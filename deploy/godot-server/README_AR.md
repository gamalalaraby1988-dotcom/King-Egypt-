# حاوية خادم KING OF EGYPT CITY — بيئة الاختبار

هذه الحاوية مخصصة لخادم Godot المخصص في بيئة Supabase TEST فقط. لا تنشرها على الإنتاج.

## البناء

نفّذ البناء من جذر المستودع:

```sh
docker build -f deploy/godot-server/Dockerfile -t king-city-server:staging .
```

الصورة تستخدم Godot 4.7.2 القياسي لنظام Linux x86_64، وتستورد موارد المشروع أثناء بناء الصورة. اجتاز GitHub Actions بناء الصورة بنجاح في التشغيل رقم 3 (24 نوفمبر 2026)، بما في ذلك خطوة Build image. هذا يثبت نجاح بناء الصورة واستيراد الموارد فقط؛ ولا يثبت تشغيل الحاوية أو اتصال اللاعبين أو نشر الخادم.

## متغيرات البيئة المطلوبة

- `KING_CITY_SUPABASE_URL=https://unwrlvyjrtdwobcktetd.supabase.co`
- `KING_CITY_SUPABASE_PUBLISHABLE_KEY`: مفتاح Publishable الخاص بمشروع TEST فقط.
- `KING_CITY_SESSION_SERVER_ID`: مثل `city-egypt-staging-01`.
- `KING_CITY_SESSION_REGION=egypt`.
- `KING_CITY_SESSION_ENDPOINT`: عنوان WSS عام حقيقي يصل إلى الخادم.
- `KING_CITY_SESSION_DIRECTORY_HMAC_SECRET_B64`: سر الدليل المطابق لـ `CITY_SESSION_SERVER_KEYS_JSON` في وظيفة TEST.
- `KING_CITY_TLS_KEY_PATH` و`KING_CITY_TLS_CERT_PATH`: مسارا مفتاح TLS وشهادة TLS داخل الحاوية.
- `KING_CITY_GAME_PORT`: المنفذ TCP الذي يمرره مزود الاستضافة إلى عملية Godot؛ الافتراضي 2456.
- `KING_CITY_SESSION_CAPACITY`: السعة التشغيلية لهذا الخادم من 1 إلى 64 لاعبًا؛ الافتراضي 64. القيمة نفسها تُستخدم لقبول الاتصالات وتسجيل السعة في دليل الجلسات، حتى لا يعلن الخادم رقمًا أكبر من حد القبول الفعلي.

يمكن إضافة أسرار ميزات أخرى لاحقًا، مثل `KING_CITY_PROOF_HMAC_SECRET_B64` و`KING_CITY_JET_SKI_RESULTS_HMAC_SECRET_B64`، بعد إعدادها في TEST. لا تضع أي مفاتيح أو شهادات أو أسرار في Git أو في صورة Docker.

## اختبار قبول الاتصالات

يشغّل GitHub Actions حاوية TEST مع شهادة TLS مؤقتة، ثم ينفذ اختبار WSS تدريجيًا عند 20 و30 و50 و64 اتصالًا، ويتحقق من بقاء الاتصالات ضمن السعة ورفض الاتصال الزائد. تُجمع سجلات الخادم ولقطة Docker stats عند نهاية الاختبار.

هذا اختبار قبول اتصالات النقل فقط: لا ينشئ حسابات لاعبين حقيقية، ولا ينفذ المصادقة أو حركة الشخصيات أو مزامنة المدينة أو اختبارًا طويل المدة. لذلك لا يُعد وحده إثباتًا لسعة إنتاجية آمنة. يجب استكماله باختبار لعب متزامن موثق على خادم TEST مستضاف وقياس مستمر للمعالج والذاكرة وزمن الاستجابة قبل إعلان السعة المعتمدة.

## التوسع وعدد اللاعبين

الحد الأعلى الحالي لكل عملية خادم هو 64 لاعبًا، لأن سياسة توزيع الجلسات تقبل سعة تصل إلى 64. يمكن تشغيل عدة عمليات/نسخ خادم مستقلة في المنطقة نفسها، ويختار دليل الجلسات النسخة المناسبة لكل لاعب أو مجموعة؛ وبذلك يزيد العدد الإجمالي للمدينة عبر عدة خوادم. هذا لا يعني أن أكثر من 64 لاعبًا قد اختُبروا فعليًا، ولا يعني أن عملية واحدة تستطيع تجاوز 64. رفع الحد داخل النسخة الواحدة يحتاج تعديلًا منسقًا في الخادم وسياسة التوزيع والتحقق في الدليل واختبارات تحميل قبل اعتماده.

## منع الاتصال بالإنتاج

يفرض ملف التشغيل أن يكون `KING_CITY_SUPABASE_URL` مساويًا تمامًا لرابط TEST وأن يكون مفتاح TEST حاضرًا. إذا غاب أي منهما، تتوقف الحاوية بدل الرجوع إلى إعدادات الإنتاج الموجودة في `project.godot`.

## متطلبات الشبكة — شرط اعتماد المضيف

خادم Godot الحالي ينشئ مستمع TLS/WSS بنفسه على `0.0.0.0` والمنفذ المحدد. لذلك يجب أن يتيح مزود الاستضافة وصول TCP عامًا إلى هذا المنفذ، أو يثبت توافق طبقة التوجيه لديه مع TLS/WSS من طرف إلى طرف إلى منفذ التطبيق. دعم WebSocket عبر وكيل HTTP وحده لا يثبت تلقائيًا توافقه مع هذا الخادم.

قبل اختيار Back4app أو أي مزود، يجب إثبات ما يلي:
1. السماح باتصالات TCP/WSS عامة إلى المنفذ المخصص، وليس HTTP فقط.
2. وصول الاتصال إلى منفذ الحاوية نفسه دون إنهاء TLS بطريقة تتعارض مع TLS داخل Godot.
3. إمكانية تركيب شهادة ومفتاح TLS كملفات أسرار للقراءة فقط.
4. استمرار الحاوية وعدم إيقافها بسبب الخمول، ووجود مساحة ذاكرة كافية لتحميل مشهد المدينة.

لا توجد هنا أي بيانات اعتماد لمضيف، ولا يُنشأ عنوان WSS تلقائيًا.

## التخزين

اربط وحدة تخزين دائمة على `/data` لحفظ ملفات بيانات الخادم المحلية، بما فيها صندوق نتائج سباق الجت سكي عند استخدامه.

## الحالة

هذه ملفات إعداد أولية قابلة للمراجعة. نتيجة بناء الصورة: ناجح في GitHub Actions، تشغيل رقم 3. لم يُثبت بعد أن Back4app يدعم منفذ TCP/WSS المطلوب أو أن ذاكرته المجانية تكفي لمشهد المدينة. لا تعتبر الحاوية منشورة أو تعدد اللاعبين جاهزًا قبل اختبار تسجيل الخادم والنبضات والاتصال بعميلين حقيقيين على الأقل في TEST.
