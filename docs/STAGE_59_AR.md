# المرحلة 59 — إظهار المارة بشخصيات المدينة

## الهدف
استبدال الشكل التجريبي البسيط للمارة بنموذج الشخصية الموجود بالفعل في المشروع، حتى يصبح وجودهم واضحًا بصريًا.

## التغييرات
- يعيد `pedestrian.gd` استخدام المشهد `scenes/characters/avatar_visual.tscn` بدل كبسولة هندسية منفردة.
- تنويع الإطلالات باستخدام خيارات الملابس والتسريحات الموجودة داخل المشروع، دون إضافة ملفات أصول جديدة.
- ربط حالة المشي والتوقف بحركة نموذج الشخصية الموجودة.
- الإبقاء على نظام المسارات والتفاعل ومواقع سكان المدينة وسيارات المرور كما هي.

## حدود التحقق
- تمت مراجعة الملفات المصدرية وفحص الأرشيف بعد التعديل.
- لم يتم تشغيل Godot 4.7.2، لذلك لم يتم التحقق بصريًا داخل المحرك من الظهور أو مواضع الشخصيات، ولم يتم بناء APK أو اختبار Android.
- هذه الشخصيات تستخدم نموذجًا هندسيًا بديلًا موجودًا أصلًا في المشروع، وليست نماذج بشرية نهائية عالية التفاصيل.
