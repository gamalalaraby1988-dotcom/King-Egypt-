# المرحلة 11 — ملامح الوجه وتسريحات الشعر ونقاط استبدال الأصول

## ما أضيف
- تفاصيل وجه هندسية أولية: عينان، حدقتان، حاجبان، أنف، فم وأذنان.
- ثلاث تسريحات تجريبية قابلة للاختيار: قصير، طويل، ومجعد.
- إضافة اختيار التسريحة إلى خزانة الملابس مع حفظها محليًا بجانب الإطلالة.
- نقاط تركيب مستقلة `OutfitMount` و`HairMount`.
- دعم تحميل مشاهد Godot مستقلة للملابس والتسريحات عند توفر الملفات في مجلدات الأصول المحددة.
- عند غياب الأصول الخارجية، يستمر استخدام الأشكال الهندسية التجريبية دون تعطيل الخزانة.

## حدود المرحلة
- ملامح الوجه والشعر والملابس الحالية أشكال هندسية مؤقتة وليست نماذج فنية نهائية.
- لا يوجد حتى الآن نظام عظام/تحريك Rig أو تعبيرات وجه أو تخصيص دقيق للأنف والعينين.
- لا تتضمن الحزمة ملفات Blender أو FBX أو أصولًا تجارية جاهزة.
- يلزم لاحقًا إنتاج نماذج فنية متناسقة، وضبط المقاسات والخامات، ثم اختبارها مع حركات اللاعب.
- لم يتم تشغيل المشروع داخل Godot أو اختباره على هاتف Android؛ محرك Godot غير متوفر في بيئة البناء الحالية.
