# المرحلة 47 — التفاعل القريب الواضح والمترجم

## ما أضيف
- توحيد نص التلميح وزر التفاعل بالعربية والإنجليزية حسب لغة اللعبة/الهاتف.
- إظهار اسم المبنى أو لوحة الوظيفة أو الموظف القريب مع فعل مناسب: دخول، تفاصيل وظيفة، استئجار، فتح متجر، أو تحدث.
- إبقاء زر التفاعل مخفيًا عند الابتعاد، وإظهار إرشاد بسيط للاقتراب عند عدم وجود هدف قريب.
- إضافة هامش خروج صغير للهدف الحالي لتقليل وميض الزر عند حافة نطاق التفاعل.
- توضيح حالة ركوب الحيوان وزر النزول، دون تغيير نظام الركوب أو المكافآت.
- تحديث النصوص فور تغيير اللغة، مع إعادة استخدام واجهة HUD الحالية دون أصول إضافية.

## حدود المرحلة
- يعتمد اكتشاف القرب على مجموعة `city_interactables` ونطاق التفاعل المحدد لكل عنصر.
- التفاعل يفتح الواجهة/الحوار الموجود؛ لا يضيف انتقالًا تلقائيًا داخل المباني.
- لا يوجد تحقق من خط الرؤية أو حجب الجدران بين اللاعب والعنصر بعد.

## التحقق
- فحص مفاتيح الترجمة العربية والإنجليزية ودوال تحديد الهدف وعرض الواجهة.
- فحص سلامة ZIP وعدد الملفات والحجم.
- لم يتم تشغيل Godot 4.7.2 أو بناء APK أو اختبار Android.
