# استعادة جلسة المؤسس عبر Android Keystore

## الهدف
استعادة جلسة Supabase بعد إعادة تشغيل اللعبة دون كتابة access token أو refresh token كنص صريح داخل ملفات اللعبة.

## واجهة الربط التي ينتظرها العميل
يبحث `FounderAuthClient` عن Android native singleton باسم `FounderSecureStorage`، ويشترط الواجهة التالية:
- `is_available() -> bool`: تأكيد أن التخزين الآمن متاح ومهيأ.
- `save_secret(alias: String, value: String) -> bool`: حفظ السر.
- `load_secret(alias: String) -> String`: استعادة السر أو إرجاع نص فارغ.
- `delete_secret(alias: String) -> void`: حذف السر.

يُحفظ refresh token فقط تحت الاسم الثابت `king_of_egypt_city.founder.refresh_token.v1`. لا يُحفظ access token؛ بعد تشغيل اللعبة يُستعاد refresh token ويُرسل مباشرة إلى Supabase للحصول على جلسة جديدة مع تدوير refresh token.

## متطلبات تنفيذ Android الأصلي
- يجب أن يستخدم التنفيذ Android Keystore بمفتاح AES-GCM غير قابل للتصدير، مع IV عشوائي جديد لكل عملية تشفير.
- تُحفظ البيانات المشفرة فقط في مساحة التطبيق الخاصة؛ لا تحفظ المفتاح أو النص الصريح في SharedPreferences أو ConfigFile أو ملفات user://.
- يجب ربط بيانات التشفير بالتطبيق/المستخدم، ورفض البيانات التالفة أو غير القابلة لفك التشفير.
- لا تُسجل الرموز أو البيانات المشفرة الحساسة في Logcat.
- عند تسجيل الخروج أو رفض refresh token نهائيًا، احذف السر المحفوظ.
- عند فشل الشبكة أثناء الاستعادة، احتفظ بالرمز المشفر وأعد المحاولة؛ لا تعتبر انقطاع الشبكة تسجيل خروج.
- إذا فشل الحفظ بعد تدوير refresh token، احذف النسخة القديمة التي قد أصبحت غير صالحة، وأبقِ الجلسة الحالية في الذاكرة فقط.

## الحالة الحالية والحدود
- أضيفت في GDScript نقطة تكامل اختيارية للـ singleton واستعادة refresh token وتجديده فور بدء التشغيل.
- **لم تتم إضافة Android native plugin بعد**؛ لذلك لن تتوفر استعادة دائمة فعلية حتى يُنفذ المكوّن الأصلي ويُسجل singleton باسم الواجهة أعلاه ضمن إعدادات Android export.
- عند غياب المكوّن، لا يُستخدم أي تخزين نصي بديل؛ تستمر الجلسة في الذاكرة فقط.
- لا تعتبر هذه المرحلة مكتملة أمنيًا أو جاهزة للإنتاج قبل إضافة plugin واختباره على Android فعليًا.
- لا يشمل ذلك تخزين PIN أو تذكرة المؤسس؛ لكل منهما دورة أمان مستقلة.
