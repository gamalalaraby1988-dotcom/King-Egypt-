# جرد موارد إعادة الاستخدام للكازينو الأوروبي VIP

**الفرع:** `remove-job-boards-expand-upgrade-buildings`
**نقطة الفحص:** `66ef19e10a1c9a10fa14ed30af44d3ae00aa651f`
**النطاق:** مراجعة ساكنة للملفات، دون تشغيل اللعبة.

## موارد موجودة ويمكن الاستفادة منها

| المورد | موضعه | ما يمكن الاستفادة منه | القيد |
|---|---|---|---|
| غرفة المبنى الداخلية | `scripts/main.gd` — `_create_building_interior()` | مساحة داخلية واحدة، أرضية وجدران ومدخل وإضاءة ولافتة | هندسة بدائية وليست تصميمًا فنيًا نهائيًا |
| إنشاء الصناديق والخامات | `_create_box()`, `_material()`, `_get_city_box_mesh()`, `_get_city_collision_shape()` | مشاركة خامات وMesh وCollisionShape حسب المقاس واللون | لا ينتج تفاصيل فنية دقيقة أو نماذج ماكينة |
| أثاث المطعم | `_create_interior_furnishings()` | طاولات ومقاعد هندسية أولية؛ يمكن إعادة استخدام نمطها أو وظائف إنشائها | لا توجد طاولات كازينو أو ألعاب مخصصة |
| أثاث المتجر | `_create_interior_furnishings()` | وحدات رفوف وخامات خشبية أولية | الرفوف ليست ماكينات ولا وحدات عرض VIP |
| مقعد الانتظار العام | `_create_interior_furnishings()` | مقعد بسيط يمكن أن يخدم منطقة انتظار ثانوية | شكله عام ولا يمثل أريكة فاخرة |
| موظف الخدمة | `scripts/service_npc.gd` | شخصية خدمة بسيطة مع اسم ودور وحوار عبر نظام التفاعل الموجود | شكل Capsule ورأس Sphere مؤقت؛ لا يمثل شخصية شبه واقعية نهائية |
| نظام الشخصية | `scenes/characters/avatar_visual.tscn`, `scripts/avatar_visual.gd` | مرجع لشخصية اللاعب/الشخصيات وحالات الحركة | السكربت يصرح أن المجسمات الحالية Placeholder؛ مشاهد الملابس والشعر الخارجية المشار إليها غير موجودة في شجرة الملفات الحالية |
| الانتقال الداخلي | `enter_building_interior()`, `return_from_building_interior()` | إعادة استخدام شاشة التحميل وإخفاء المدينة واستعادتها | لا حاجة إلى نظام انتقال موازٍ للكازينو |

## غير موجود ضمن شجرة الملفات المفحوصة

- مشهد مستقل للكازينو أو صالة VIP.
- نماذج ماكينات قمار أو طاولات روليت أو بوكر أو ألعاب كازينو.
- نماذج أريكة أو كراسي VIP فنية جاهزة.
- ديكورات داخلية فاخرة أو خامات زخرفية مخصصة للكازينو.
- مشهد موظف VIP نهائي أو شخصية حارس/استقبال فنية.
- أصول السفينة أو الأجنحة ليست موردًا تلقائيًا للكازينو؛ لا تُنسخ أو تُحوّل دون حاجة واعتماد منفصل.

## قرارات إعادة الاستخدام العملية

1. الاحتفاظ بمساحة الكازينو الداخلية الحالية كنموذج خفيف، وعدم إضافة مبنى خارجي.
2. الاستمرار في استخدام مخازن الخامات والمجسمات المشتركة في `main.gd` لتقليل تكرار الموارد.
3. يمكن الاستفادة من هندسة الطاولات والمقاعد الحالية كنقطة بناء فقط، مع عدم تسميتها ماكينات أو ألعابًا غير موجودة.
4. لا نضيف موظفًا افتراضيًا للكازينو قبل تحديد دوره وحواره ومهامه.
5. لا نضيف أصولًا جديدة أو نظام رهانات أو مكافآت أو أسعار قبل قرار مستقل.
6. لا توجد صالة ألعاب يومية مستقلة، ولا دمج لها كميزة منفصلة؛ هذا الخيار ملغى بتوجيه المستخدم.

## ما يحتاج قرارًا قبل استكمال التفاصيل

- أنواع ألعاب الكازينو التي يريدها المستخدم فعليًا.
- هل المقصود صالة VIP اجتماعية/استعراضية فقط أم ألعاب كازينو تفاعلية أيضًا.
- شكل موظف الاستقبال أو الحراسة ودورهما، إن وُجدا.

لا يُفترض أي خيار من هذه الخيارات في التنفيذ قبل اعتماده.
