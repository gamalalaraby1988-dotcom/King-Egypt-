# اختبار وضعية استخدام الهاتف

أُضيف الاختبار `tests/avatar_phone_use_pose_contract_test.gd` للتحقق من ربط الهاتف بالذراع اليمنى، وظهوره عند تفعيل `set_phone_using(true)`، وتطبيق زاوية الذراع والرأس المحددة، ثم إخفائه واستعادة الوضعية الافتراضية عند إيقاف الاستخدام.

يُنفّذ الاختبار ضمن سير عمل `Godot project check` عبر خطوة `Run avatar phone-use pose contract test`.

هذا اختبار لعقد الحالة والتحويلات البرمجية، وليس بديلًا عن مراجعة لقطة مرئية للشخصية أثناء حمل الهاتف.
