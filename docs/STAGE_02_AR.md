# المرحلة 02 - تحكم اللمس والمدينة الأولية

## الإضافات
- عصا افتراضية على يسار الشاشة للتحرك في الاتجاهات الأربعة.
- زر RUN على يمين الشاشة لتفعيل الجري أثناء الضغط.
- استمرار دعم لوحة المفاتيح للتجربة على الكمبيوتر.
- إنشاء عناصر التحكم كطبقة واجهة منفصلة عن العالم ثلاثي الأبعاد.

## الاستخدام
شغّل المشروع على جهاز يدعم اللمس أو محاكي أندرويد. حرّك العصا الافتراضية، واستمر في الضغط على RUN للجري. على الكمبيوتر استخدم WASD أو الأسهم وShift.

## حدود هذه المرحلة
لم يتم بعد إضافة سحب الكاميرا بالإصبع، أو نظام قيادة السيارات، أو اختبار فعلي على جهاز أندرويد. يلزم فتح المشروع في Godot 4.7.2 وفحص الأخطاء قبل اعتماد المرحلة.
