# قائمة تسليم وفحص أصول الشخصيات الـ16
## KING OF EGYPT CITY

### الغرض
هذه القائمة هي بوابة عملية لاستلام النماذج النهائية وربطها. تعتمد دليل الاتجاه الفني وملف المعرفات ومسارات الأصول. لا تعني هذه الوثيقة أن أي نموذج قد أُنتج أو سُلّم.

### قواعد ثابتة
- العدد 16: ثمانية رجال وثماني نساء.
- تُحفظ المعرفات التقنية الستة عشر ومسارات Godot كما هي في `CHARACTER_ASSET_PRODUCTION_AND_ID_MAPPING_AR.md`.
- لكل شخصية زي كامل ثابت؛ لا خزانة ملابس أو تخصيص ملابس/شعر/جسم أو تبديل ألوان.
- لا تُفعّل أسعار أو مشتريات أو خصومات Cash/Gems. إتاحة الشخصيات المدفوعة تظل غير مفعلة حتى اعتماد الاقتصاد الموحد.
- لا تُعد الصور المرجعية أو صور ImageGen أو مجسمات AvatarVisual المؤقتة نماذج نهائية.

### حزمة التسليم لكل شخصية
يُسلّم مجلد مستقل باسم ID الثابت، ويحتوي على الأقل:
1. `source/`: ملف المصدر القابل للتحرير من أداة النمذجة، مع إصدار الأداة وأي إضافات لازمة.
2. `export/`: ملف GLB/ glTF نهائي مضبوط للاستيراد في Godot، دون مسارات خامات خارجية مفقودة.
3. `character.tscn`: مشهد Godot مستقل في المسار المعتمد.
4. `textures/`: خامات PBR والنسخ المضغوطة المناسبة لمنصة Android، مع عدم تضمين نسخ مكررة غير مستخدمة.
5. `preview/`: لقطات أمامية وخلفية وثلاثة أرباع ولقطة وجه، إضافة إلى صورة بطاقة الاختيار.
6. `README_AR.md`: ID، اسم الشخصية، إصدار المصدر، إعدادات التصدير، عدد المضلعات والمواد والعظام، دقة وأحجام الخامات، حجم الملفات، وأي قيود معروفة.

### معيار التوافق الموحد
- اتجاه أمامي ومحور ومقياس موحدان، ونقطة أصل عند القدمين.
- هيكل عظمي موحد أو متوافق مع معيار Rig واحد موثق للمشروع.
- أسماء عظام ومسارات Skeleton واضحة وثابتة، دون اعتماد على أسماء عشوائية من أداة التصدير.
- توفير حالات الحركة الأساسية المطلوبة للمشروع: Idle وWalk وRun وSit، مع اختبار انتقالاتها وعدم تشوه المفاصل.
- خامات PBR موحدة الجودة، مع تقليل عدد المواد والخامات حيث لا يؤثر ذلك على المظهر.
- إعداد LOD وضغط الخامات وحجم الملفات وفق قياسات فعلية على Android؛ لا تُعتمد أرقام أداء افتراضية.
- لا شعارات تجارية حقيقية، ولا رموز ثقافية نمطية تختزل هوية الشخصية.

### قائمة فحص الاستلام
لكل ID، تُسجّل النتيجة كـ `لم يُسلّم` أو `قيد الفحص` أو `مقبول` أو `مرفوض مع سبب`:
- [ ] ملف المصدر القابل للتحرير موجود ويفتح.
- [ ] ملف GLB/glTF يفتح دون أخطاء أو مراجع مفقودة.
- [ ] مشهد `character.tscn` موجود في المسار الثابت الصحيح.
- [ ] الشخصية مطابقة لبطاقة التصميم والزي الثابت.
- [ ] الوجه والشعر والبنية والوقفة مميزة عن الشخصيات الأقرب إليها.
- [ ] القياس والاتجاه ونقطة الأصل متوافقة مع بقية المجموعة.
- [ ] الـRig والأنيميشن الأساسية تعمل دون تشوهات ظاهرة.
- [ ] الخامات والمواد موجودة ومضبوطة، ولا توجد خامات غير مستخدمة.
- [ ] لقطات المراجعة الأربع وبطاقة الاختيار مرفقة.
- [ ] تقرير المضلعات والمواد والعظام والخامات وحجم الملفات مكتمل.
- [ ] استيراد Godot ومعاينة الاختيار والظهور داخل العالم اجتازت الاختبار.
- [ ] قياس الأداء على جهاز Android المستهدف موثق فعليًا.
- [ ] مراجعة فنية وثقافية نهائية تمت.

### بوابات الاعتماد
1. **استلام الملفات:** اكتمال حزمة التسليم لكل ID.
2. **الفحص الفني:** نجاح الاستيراد، الـRig، الخامات والأنيميشن داخل Godot.
3. **الفحص البصري:** مطابقة التصميم وتميّز الشخصيات الست عشرة.
4. **فحص Android:** قياس الأداء الفعلي على الجهاز المستهدف وتوثيق النتيجة.
5. **الربط والحفظ:** ربط كل ID بمشهد الشخصية، ثم تنفيذ حفظ `selected_character_id` والتحقق منه خادميًا دون تغيير هوية الحساب أو تقدمه.
6. **التفعيل:** لا يُفعّل زر التأكيد للاعبين إلا بعد اجتياز البوابات السابقة واكتمال الحفظ الآمن.

### الحالة عند إنشاء هذه القائمة
- لم تُسلّم نماذج 3D نهائية موثقة لأي من الشخصيات الست عشرة.
- لم يُثبت اجتياز استيراد النماذج أو Rig أو Android.
- شاشة الاختيار الحالية تستخدم معاينة مؤقتة عند غياب مشهد الشخصية النهائي، وزر التأكيد يظل معطلًا.
- هذه القائمة لا تغيّر كود اللعبة ولا قاعدة البيانات ولا الاقتصاد، ولا تنفذ أي شراء أو منح عملات.
