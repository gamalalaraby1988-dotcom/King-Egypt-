# المرحلة 69 — نظام المجموعة الأساسي

- إضافة زر «مجموعتي» لفتح نافذة مستقلة تعرض أعضاء المجموعة وخاناتها.
- الحد الأقصى أربعة لاعبين: قائد وثلاثة أعضاء.
- دعوة الصديق من نافذة تفاعل اللاعب تسجل دعوة معلقة، ولا تضيفه تلقائيًا قبل القبول.
- منع تكرار دعوة اللاعب أو إضافته مرتين، ومنع تجاوز سعة المجموعة.
- توفير `resolve_group_invitation(player_id, accepted, display_name)` لاستقبال نتيجة قبول/رفض الدعوة من طبقة الشبكة لاحقًا.
- إتاحة إزالة الأعضاء مع إبقاء القائد الأساسي في مكانه.
- الإشارات `group_add_requested` و`group_member_removed` نقاط ربط لخدمة الخادم.

## حدود المرحلة
هذه إدارة حالة محلية وتجهيز واجهة وإشارات فقط. لا يوجد خادم متعدد اللاعبين متصل بعد، ولذلك لا تنتقل الدعوات أو العضويات بين أجهزة اللاعبين فعليًا. لم يتم تشغيل Godot أو بناء APK في هذه المرحلة.
