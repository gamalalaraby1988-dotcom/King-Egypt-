# المرحلة 64 – استدعاء المركبة وركوبها والنزول منها

- إضافة مركبة اللاعب إلى المدينة بالقرب من نقطة البداية.
- زر تفاعل يظهر عند الاقتراب من المركبة، مع دعم مفتاح E.
- عند الركوب: إخفاء الشخصية وتعطيل تصادمها وحركتها، وتفعيل كاميرا المركبة وواجهة القيادة.
- عند النزول: إعادة الشخصية بجانب المركبة، واستعادة التصادم والحركة والكاميرا، وإيقاف المركبة.
- واجهة القيادة مخفية خارج حالة الركوب.
- لا توجد مارة أو سيارات مرور.

لم يتم تشغيل Godot أو بناء APK؛ يلزم اختبار المشهد فعليًا داخل Godot 4.7.2 وعلى Android قبل اعتماد السلوك النهائي.
