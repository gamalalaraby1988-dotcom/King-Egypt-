# المرحلة 68 — زر سياقي حسب حالة الصداقة

## التغيير
- نافذة التفاعل المستقلة تقرأ `is_friend` ضمن بيانات اللاعب عند فتحها.
- إذا كانت القيمة `false` أو غير موجودة، يظهر زر «إضافة صديق».
- إذا كانت القيمة `true`، يظهر بدلًا منه زر «إضافة للمجموعة».
- الضغط على الزر يطلق إشارة مستقلة: `friend_add_requested` أو `group_add_requested` مع رمز اللاعب الفريد.
- يظل زر «إهداء حفلة» وخيار «تقديم بلاغ» وزر الإغلاق كما هي.

## عقد البيانات
يُمرر `open_player_interaction(player_data)` قاموسًا يتضمن `player_id` و`display_name` و`level` و`account_age`، مع `is_friend` لتحديد الزر، ويمكن تمرير `avatar_text` كرمز بديل للصورة. يجب أن تأتي حالة الصداقة من بيانات قائمة الأصدقاء/الخادم عند توفره؛ القيمة الافتراضية الآمنة هي غير صديق.

## حدود التنفيذ والتحقق
هذه مرحلة واجهة وربط إشارات محلية؛ إرسال طلب الصداقة ودعوة المجموعة فعليًا يتطلب خدمة الخادم. تم التحقق من التغييرات نصيًا ومن سلامة أرشيف ZIP، ولم يتم تشغيل Godot أو بناء APK في هذه الجلسة.
