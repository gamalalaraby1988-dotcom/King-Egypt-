# التحقق من بريد المؤسس عبر Supabase Auth

هذه المرحلة تربط اللعبة بنقطة مصادقة Supabase Auth لإرسال رمز بريد والتحقق منه. **التحقق من البريد وحده لا يمنح رتبة المؤسس أو صلاحياته**؛ إصدار استحقاق المؤسس الموقّع خطوة خادمية منفصلة لم تُنفذ بعد.

## إعدادات الإنتاج في Godot

تم ضبط الإعدادات العامة التالية في `project.godot`:
- عنوان مشروع الإنتاج: `https://lupmaktbymuaymhqsxxu.supabase.co`
- مفتاح Supabase Publishable فقط، وهو مفتاح عميل عام وليس سرًا.

لا تضع `service_role` أو أي Secret Key أو مفتاح توقيع خاص داخل Godot أو المستودع.

## تدفق رمز البريد

يستخدم العميل:
- `POST /auth/v1/otp` مع `email` و`create_user: true` لطلب رمز التحقق.
- `POST /auth/v1/verify` مع `email` و`token` و`type: email` للتحقق.
- بعد التحقق يتأكد العميل من وجود `email_confirmed_at` ومن تطابق البريد الذي أعاده الخادم.

ينشئ Supabase Auth حساب المستخدم عند أول تسجيل ناجح، ويُنشئ trigger قاعدة البيانات ملف اللاعب والمحفظة الابتدائيين. هذا لا ينشئ حساب مؤسس تجريبيًا ولا يمنح رتبة FOUNDER.

## إعدادات لوحة Supabase المطلوبة قبل إرسال أول بريد

1. افتح Authentication > Sign In / Providers وتأكد من تفعيل Email وEmail confirmations.
2. اضبط قالب Email OTP ليعرض الرمز باستخدام `{{ .Token }}` بدل الاعتماد على رابط فقط.
3. خدمة البريد المدمجة في Supabase محدودة للاختبار، ولا ترسل إلا إلى عناوين أعضاء فريق المؤسسة. للإطلاق للاعبين الحقيقيين، اربط SMTP مخصصًا من Authentication > Emails > SMTP Settings.
4. لا ترسل اختبارًا فعليًا إلى بريد المؤسس قبل مراجعة إعدادات القالب والبريد.

## ملاحظات أمان

- HTTPS فقط؛ لا يرسل العميل PIN المحلي إلى الخادم.
- رمز البريد قصير العمر ومحدود المحاولات ومعدل الإرسال حسب إعدادات Auth.
- لا تُصدر صلاحيات FOUNDER اعتمادًا على قيمة بريد أو metadata يرسلها العميل.
- يلزم لاحقًا Endpoint خادمي يتحقق من جلسة Supabase، ويطابق هوية المؤسس الأساسية المخزنة خادميًا، ثم يصدر تذكرة RSA موقعة. لا يوجد مفتاح خاص أو تذكرة إنتاج حتى الآن.
- يجب ضبط المفتاح العام المقابل في `founder/security/public_key_pem` قبل قبول أي تذكرة مؤسس.
- لا تعتبر PIN المحلي إثبات ملكية البريد؛ إنه قفل محلي منفصل.

## حدود الإنجاز الحالي

تم إعداد عميل Godot وإعدادات المشروع العامة على فرع منفصل. لم يتم إرسال بريد أو إنشاء حساب Auth للمؤسس أو تفعيل صلاحياته. لم يتم اختبار المشروع عبر Godot أو Android بعد.
