# المرحلة 12 — حركات الشخصية الأساسية

## ما أضيف
- حركة إجرائية خفيفة للشخصية دون ملفات أنيميشن خارجية: وقوف هادئ، مشي، جري، وجلوس.
- تزامن حالة الحركة مع سرعة اللاعب الفعلية.
- زر/مفتاح الجلوس: الضغط على C للتبديل بين الجلوس والوقوف؛ تتوقف الحركة الأفقية أثناء الجلوس.
- إعادة أجزاء الجسم إلى وضعها الطبيعي عند الخروج من الجلوس أو التوقف، لمنع تراكم الدوران.
- إبقاء الحركة خفيفة ومناسبة كبداية لهواتف Android، دون إضافة قفز.

## التحكم
- WASD أو الأسهم للحركة، وShift للجري.
- C للتبديل بين الجلوس والوقوف.
- عصا اللمس والجري يستمران بالعمل كما في المرحلة السابقة؛ الجلوس حاليًا مربوط بمفتاح C ويحتاج زر لمس مستقل في مرحلة واجهة التحكم التالية.

## الحدود والاختبار
- هذه حركة إجرائية أولية وليست Rig عظميًا أو أنيميشن احترافيًا.
- لا توجد حركة أصابع أو تعبيرات وجه أو تفاعل جلوس مع كراسي محددة.
- لا يتوفر Godot في بيئة الإنشاء الحالية؛ تم تحديث الملفات وفحص محتويات الحزمة بنيويًا فقط، ولم يتم تشغيل المشروع أو اختباره على Android.
