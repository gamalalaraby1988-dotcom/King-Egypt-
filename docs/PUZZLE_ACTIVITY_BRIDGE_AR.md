# ربط أنشطة المدينة بقطع البازل — المرحلة 77

## مسار التنفيذ
1. خادم Godot الموثوق يتحقق من إكمال الوظيفة أو المهمة من موضع اللاعب وحالة النشاط.
2. لا يرسل العميل اختيار القطعة. الخادم يحدد القطعة من خريطة إعدادات خادمية معتمدة.
3. الخادم يوقع بيانات الحدث بـ HMAC؛ لا يُرسل السر إلى تطبيق Android.
4. Edge Function باسم `game-puzzle-piece-issuer` تتحقق من التوقيع والبصمة والمهلة ثم تستدعي `issue_server_puzzle_piece_proof` بصلاحية الخادم.
5. يعود إثبات قصير العمر إلى جلسة اللاعب نفسها، ويطالب العميل به عبر `claim_verified_puzzle_piece` باستخدام JWT الخاص بحسابه.
6. قاعدة البيانات تضيف القطعة مرة واحدة وتمنع إعادة المطالبة.

## مصادر النشاط الموصولة في هذه الدفعة
- الوظائف: `courier_delivery`, `city_guide`, `city_maintenance`.
- المهام: `mission_shop`, `mission_restaurant`, `mission_employment`.
- لم تُوصل ماكينات الأركيد أو أنشطة المشي اليومية في هذه الدفعة؛ لا يظهر لها حتى الآن مسار نتيجة لعب خادمي موثوق يثبت الفوز/الإكمال. لا نقبل نتيجة يرسلها العميل وحده.

لا يتم إصدار قطعة لمجرد إرسال طلب من العميل؛ يجب أن يعلن خادم اللعب إكمال النشاط أولًا.

## إعداد الخادم المطلوب لتفعيل الإصدار
يُقرأ الإعداد على خادم Godot المخصص فقط:

- `KING_CITY_PUZZLE_SEASON_ID`: UUID لموسم نشط موجود في قاعدة البيانات.
- `KING_CITY_PUZZLE_ACTIVITY_PIECES_JSON`: خريطة معتمدة من `activity_kind:activity_id` إلى `piece_id`.

مثال توضيحي غير صالح للتشغيل قبل استبدال القيم بمعرفات موسم وقطع موجودة ومعتمدة:

```json
{
  "job:courier_delivery": "approved_piece_id_01",
  "mission:mission_shop": "approved_piece_id_02"
}
```

إذا لم يُضبط الموسم أو خريطة القطع، يظل إصدار قطع البازل متوقفًا بأمان، ولا تتأثر الوظائف والمهام الحالية أو إثباتات مكافآتها.

## ما لم يتم تفعيله
- لم يُنشأ موسم أو كتالوج صور/قطع جديد.
- لم تُخترع نسب سقوط أو أوزان احتمالية أو أسعار أو مكافآت.
- لا يُعد وجود Edge Function أو الربط البرمجي تفعيلًا لموسم إنتاجي.
- يجب ضبط متغيرات الخادم بعد اعتماد موسم وكتالوج وخريطة توزيع صريحة.
- هذا الربط لا يفعّل مكافآت المحفظة ولا يغيّر أرصدة اللاعب.

## الأمان
- HMAC secret يبقى في بيئة الخادم وEdge Function فقط.
- Supabase secret/service-role key لا يدخل Godot أو Android.
- كل مطالبة تعتمد على هوية JWT، والقطعة المحددة في الإثبات، وقيد منع التكرار في قاعدة البيانات.
