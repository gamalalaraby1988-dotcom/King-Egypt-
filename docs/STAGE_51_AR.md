# المرحلة 51 — موظفو المباني والتفاعل الداخلي

## الهدف
إضافة موظف يمكن رؤيته والتفاعل معه داخل كل مبنى قابل للدخول، مع إعادة استخدام نظام الشخصيات والتفاعل الحالي لتقليل التعقيد وحجم المشروع.

## ما تم تنفيذه
- إضافة صاحب متجر داخل المتجر؛ الضغط على زر التفاعل يفتح واجهة المتجر الحالية عبر ShopManager.
- إضافة موظف داخل المطعم يقدم حوارًا إرشاديًا حول الطلبات والتوصيل.
- إضافة مستشار داخل مركز التوظيف يوجه اللاعب إلى لوحة الوظائف والفرص المتاحة.
- وضع الموظفين داخل المساحة الداخلية نفسها بحيث لا يظهرون في المدينة الخارجية.
- دعم العربية والإنجليزية لأسماء الموظفين وأدوارهم وحواراتهم، مع تحديث الاسم المعروض من بيانات التفاعل المترجمة.
- إعادة استخدام `service_npc.gd` ومجسماته الهندسية الخفيفة؛ لا صور أو خامات أو مكتبات جديدة.
- لم تتم إضافة مكافآت أو خصومات أو معاملات جديدة إلى حوارات المطعم ومركز التوظيف.

## حدود المرحلة
- موظف المتجر يفتح واجهة المتجر الموجودة؛ لم تتم إضافة منتجات أو أسعار جديدة.
- موظف المطعم ومستشار التوظيف يقدمان تفاعلًا حواريًا أوليًا فقط. ربط طلبات الطعام والتقديم والتوظيف الكامل يحتاج مراحل مستقلة.

## الفحص
تم فحص التعديلات نصيًا ومراجعة مفاتيح العربية والإنجليزية وبنية الأرشيف. لم يتم تشغيل Godot 4.7.2 أو بناء APK أو اختبار Android في هذه البيئة.
