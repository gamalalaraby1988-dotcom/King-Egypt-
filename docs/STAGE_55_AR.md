# المرحلة 55 — تفاعل اجتماعي خفيف بين المارة

- [x] السماح لمارٍ متوقف ببدء تفاعل قصير مع مارٍ قريب متوقف.
- [x] جعل الشخصية الأقرب/الأسبق حسب معرّف المشهد هي التي تبدأ، لتجنب بدء التفاعل مرتين من الطرفين.
- [x] توجيه الشخصيتين نحو بعضهما أثناء التفاعل.
- [x] إضافة إيماءات جسدية بسيطة لمدة قصيرة باستخدام المجسم الحالي.
- [x] إنهاء التفاعل إذا ابتعد الطرف الآخر أو اختفى.
- [x] إضافة فترة تهدئة مستقلة لمنع تكرار التفاعلات بصورة متواصلة.
- [x] عدم إضافة أصوات أو واجهات أو أصول جديدة أو مكافآت.
- [ ] اختبار السلوك داخل Godot 4.7.2 وعلى Android، خصوصًا مع زيادة عدد المارة.

التحقق في هذه المرحلة: فحص ZIP ومراجعة مصدر GDScript وتحديث الوثائق. لم يتم تشغيل Godot 4.7.2 أو بناء APK أو اختبار Android.
