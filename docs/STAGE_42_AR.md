# المرحلة 42 — تحسين شبكة الطرق ونقاط الاتصال

## الهدف
تحسين المسارات الإرشادية ضمن شبكة الطرق الموجودة في النموذج، دون اختراع شوارع أو إضافة أصول ثقيلة.

## التعديلات
- إسقاط نقطة انطلاق اللاعب على أقرب محور طريق معروف، مع حصر الإسقاط ضمن الامتداد الحالي للطريق.
- مقارنة مساري الانعطاف الممكنين حول تقاطع المحورين واختيار المسار الأقصر حسابيًا.
- الحفاظ على مسار مخيم الحيوانات عبر وصلة المدخل والطريق الشمالي وطريق المخيم.
- توحيد ارتفاع نقاط المسار إلى مستوى الأرض وإزالة النقاط المتكررة.
- إضافة دالة لحساب طول سلسلة نقاط المسار، لاستخدامها في مقارنة البدائل.

## الحدود الحالية
- شبكة المدينة لا تزال محورين رئيسيين متقاطعين، مع ثلاثة مقاطع طريق متصلة بمخيم الحيوانات.
- بعض المسافة من محور الطريق إلى المبنى النهائي تظل وصلة اقتراب مباشرة؛ لا توجد بعد بيانات ممرات حول كل مبنى.
- لم تُضف البوابة الملكية أو الميناء إلى الملاحة لعدم تثبيت إحداثياتهما داخل المشهد.
- النظام إرشادي فقط ولا يحرك اللاعب تلقائيًا ولا يغير المكافآت.

## الفحوص
- تمت مراجعة ملفات المصدر والوثائق وفحص سلامة أرشيف ZIP وعدد ملفاته.
- لم يتم تشغيل Godot 4.7.2 أو بناء APK أو اختبار الأداء واللمس على Android.
