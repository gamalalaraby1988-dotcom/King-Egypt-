# المخيم الصحراوي الملكي — اعتماد التنفيذ

الحالة: تنفيذ أولي على فرع مستقل، بانتظار الفحص والبناء.

- استبدال موقع مخيم الحيوانات بموقع المخيم الصحراوي الملكي.
- خيام ضيافة وخيمة ملكية للمؤسس، جلسات حول موقد نار، فوانيس، مائدة ضيافة، نخيل وواحة تصوير.
- الجمال والخيول مجسمات ثابتة للزينة فقط: لا ركوب، لا تأجير، لا موظف حيوانات، ولا نقاط تفاعل للحيوانات.
- محطة الحفلات تستخدم مجموعة party_stations الحالية، ويظل زمن الحفلة الموحد 20 ثانية وفق القرار المعتمد.
- المجسمات مصنوعة من Meshes خفيفة مبدئيًا؛ الأصول الفنية النهائية وقياس الأداء على Android ما زالا مطلوبين.
- لا تُعد هذه النسخة APK نهائية؛ يجب تشغيل فحوص Godot والبناء عند حل عائق GitHub Actions المالي.

- أُلغي المنتجع الملكي بالكامل من مسار التشغيل: أزيل إنشاء المنتجع والبوابات وخيار الخروج الخاص به.
- أُبقي طريق الوصول المشترك وأعيدت تسميته لطريق المخيم الصحراوي؛ ويظل متصلًا بوصلة طريق قمة الملوك.
- أصبح خيار التنقل السريع من المباني يعرض المخيم الصحراوي بدل المنتجع.
