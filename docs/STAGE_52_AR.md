# المرحلة 52 — تحسين حوار موظفي المباني

- توحيد نصوص نافذة حوار موظفي الخدمة عبر مفاتيح اللغة بدل النصوص العربية الثابتة.
- إضافة ترجمة عربية وإنجليزية لرسالة المعلومات، والتنبيه بأن الحوار لا يمنح مكافآت، وزر الإغلاق.
- تحديث زر الإغلاق فور تغيير اللغة أثناء اللعب.
- إخفاء زر قبول المهمة غير المستخدم أثناء حوار الموظف، ثم إعادته عند إغلاق النافذة حتى لا يتداخل مع واجهات المهام الأخرى.
- لم تتم إضافة مكافآت أو مهام تلقائية أو نظام طلبات للمطعم.

## التحقق
- فحص نصي لمفاتيح الترجمة في اللغتين.
- فحص نصي لتحديث زر الإغلاق وإخفاء/إعادة إظهار زر القبول.
- لم يتم تشغيل Godot 4.7.2 أو بناء APK أو اختبار Android.
