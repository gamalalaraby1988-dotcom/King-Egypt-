# المرحلة 46 — ربط الملاحة بمداخل المباني ونقاط التفاعل

## ما أضيف
- تعريف نقاط وصول عند أبواب المتجر والمطعم ومركز التوظيف بدل توجيه اللاعب إلى مركز المبنى.
- ربط وجهات التوصيل ومرشد المدينة والصيانة بنقاط الوقوف عند لوحات الوظائف.
- إبقاء مخيم الحيوانات على نقطة الوصول الحالية المتصلة بمسار المخيم.
- جعل نظام الملاحة وإعادة حساب المسار يستخدمان نقطة الوصول نفسها.
- استخدام نقاط Vector3 وثوابت فقط؛ لا صور أو خامات أو مكتبات جديدة.

## حدود المرحلة
- نقاط الوصول محسوبة من إحداثيات المباني ولوحات الوظائف الحالية في `main.gd`، وليست أبوابًا هندسية جديدة.
- لم تتم إضافة انتقال تلقائي داخل المباني أو فتح أبواب أو تفعيل التفاعل تلقائيًا عند الوصول.
- المواقع تحتاج مراجعة بصرية داخل Godot بعد اكتمال الشكل النهائي للمباني.

## التحقق
- مراجعة تطابق مفاتيح الوجهات السبعة مع جدول نقاط الوصول.
- فحص نصي لوجود دالة حل نقطة الوصول واستخدامها قبل بناء المسار.
- فحص سلامة ZIP وعدد الملفات والحجم.
- لم يتم تشغيل Godot 4.7.2 أو بناء APK أو اختبار Android.
