# المرحلة الثامنة — الملف الشخصي والإعدادات الأساسية

## الإضافات
- زر لفتح نافذة الملف الشخصي والإعدادات.
- تعديل اسم اللاعب.
- عرض المستوى والخبرة والمال والرقائق من نظام التقدم.
- إعداد مستوى الصوت الرئيسي.
- اختيار جودة الرسوم (منخفضة/متوسطة/مرتفعة) مع التحكم في ظلال الضوء الرئيسي.
- حفظ الاسم والإعدادات في ملف الحفظ المحلي نفسه مع الحفاظ على بيانات التقدم.

## إصلاح توافق
- تم تعديل ترتيب إعداد سكربت المباني التفاعلية قبل تعيين خصائصها، لتفادي الوصول إلى خصائص قبل ربط السكربت.
- حفظ التقدم يقرأ ملف الإعدادات الحالي أولًا حتى لا يمحو اسم اللاعب أو تفضيلاته.

## الحدود
- مستوى الصوت يؤثر في ناقل الصوت الرئيسي، لكن لا توجد مؤثرات صوتية مضافة بعد.
- اختيار الجودة يضبط ظلال الضوء الرئيسي فقط حاليًا، وليس كل تفاصيل الرسوم.
- لا يوجد تسجيل دخول أو مزامنة سحابية.
- لم يتم اختبار الحزمة داخل Godot 4.7.2 أو على هاتف أندرويد.
