# FounderSecureStorage — إضافة Android أصلية

هذا المجلد يحتوي مصدر Kotlin للمكوّن الذي يوفّر singleton باسم `FounderSecureStorage` لعميل Godot.

## الواجهة

- `is_available() -> bool`
- `save_secret(alias, value) -> bool`
- `load_secret(alias) -> String`
- `delete_secret(alias) -> void`

يستخدم التنفيذ AES-256-GCM عبر Android Keystore، ويحتفظ بالبيانات المشفرة فقط في مساحة التطبيق الخاصة. المفتاح غير قابل للتصدير، ويُنشأ IV جديد عشوائي لكل عملية تشفير. فشل فك التشفير يعيد نصًا فارغًا ولا يحاول استعادة بيانات غير موثوقة.

## حالة الدمج

هذا هو مصدر الإضافة فقط. لم يُنشأ ملف AAR ولم يُربط بعد بمسار Gradle/Android export في Godot؛ لذلك لا يظهر singleton داخل اللعبة حتى بناء الإضافة وتسجيلها كـ Godot Android plugin v2 ثم تفعيلها في إعدادات تصدير Android.

يجب بناء AAR باستخدام نسخة Godot Android plugin API المطابقة تمامًا لنسخة المحرر المستخدمة في المشروع (المشروع يعلن Godot 4.7). لا تستخدم AAR مبنيًا لإصدار مختلف.

## نقاط أمان يجب اختبارها قبل الدمج

1. الحفظ ثم إعادة تشغيل التطبيق ثم الاستعادة على جهاز Android فعلي.
2. رفض ملف مشفر معدل أو IV غير صالح.
3. حذف مفتاح Keystore والملف عند تسجيل الخروج.
4. سلوك إلغاء تثبيت التطبيق/استعادة النسخ الاحتياطية؛ إعداد المشروع الحالي يعطّل Android backup.
5. التعامل مع فقدان/إبطال مفتاح Keystore بعد تغيير قفل الجهاز أو سياسات النظام.
6. عدم تسجيل الرموز أو محتوى الملف في Logcat.
7. التحقق من أن التطبيق لا يكتب refresh token إلى أي ملف آخر أو إعدادات عادية.

لم يتم تشغيل Gradle أو Godot أو بناء APK أو اختبار Android في هذه المرحلة.
